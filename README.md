# The Spider-Man: Web of Shadows Recompile Project
The Spider-Man: Web of Shadows Recompile Project is a project where we recompile the game titled "Spider-Man: Web of Shadows" into Android and iOS.

[Watch Gameplay Video](https://github.com/Algerianportslab/Spider-man-Web-Of-Shadows-Wii-Recompile-Project/blob/main/spiderman%20web%20of%20shadows%20recompile%20%5B2BB9AB7%5D.mp4)

# Information

Spider-Man: Web of Shadows is a 2008 action-adventure game developed by Shaba Games and Treyarch, and published by Activision.

Spider-Man: Web of Shadows runs on a custom engine tailored for fast-paced open-world web-swinging and dynamic multi-surface combat.

# Development

Core web-swinging mechanics and ground combat loops are functional.

Shader compilation issues are currently being addressed on select GPU drivers.

# Low End Requirements (Low Graphics)
- Snapdragon 675 / MediaTek Helio G90T or equivalent and higher
- 4GB - 6GB RAM
- Android 10 and higher

# Medium End Requirements (Medium-High Graphics)
- Snapdragon 855 / Dimensity 820 or equivalent and higher
- 8GB RAM
- Android 11 and higher

# High End Requirements (High Graphics)
- Snapdragon 8 Gen 1 / Dimensity 8100 or equivalent and higher
- 12GB RAM and higher
- Android 12 and higher

Requirements may change in the future.
